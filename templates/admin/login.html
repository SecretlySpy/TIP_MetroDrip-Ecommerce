{% extends "admin/base_site.html" %} {% load i18n static %} {% comment %} Overrides Django's admin login only to add the second-factor field (ADR-P3-029). Django's own template renders `username` and `password` by name rather than looping the form, so a field added by `ConsoleAuthenticationForm` would never appear — the form would demand a token the page gave no way to type. Everything else here mirrors the upstream template so the console keeps its usual styling. The OTP field is always rendered rather than shown conditionally: the page cannot know whether this account is enrolled until credentials are checked, and branching on it after a failed attempt would leak which accounts have 2FA.
